# Level 3 - Task 2: WebSockets for Real-Time Communication

## Project
Internship Management System

## Technologies Used
- Node.js
- Express.js
- Socket.IO
- React.js

## Implemented Features

- WebSocket-based real-time communication
- Bidirectional communication between client and server
- Real-time chat functionality
- User-specific WebSocket rooms
- Real-time message delivery
- Instant UI updates without page refresh
- Socket connection and disconnection handling
- Efficient event-based communication

## Implementation

### Backend
WebSocket functionality is implemented using Socket.IO in the Express.js backend.

### Frontend
The React frontend connects to the Socket.IO server and receives messages in real time.
