# Level 3 - Task 1: Build a Full-Stack Application

## Project
Internship Management System

## Technologies Used
- React.js
- Node.js
- Express.js
- MongoDB Atlas
- JWT Authentication
- REST APIs

## Implemented Features

- Full-stack Internship Management System
- React.js frontend
- Express.js and Node.js backend
- MongoDB Atlas database integration
- REST API integration between frontend and backend
- User registration and login
- JWT-based authentication
- Role-based access control
- Internship data management
- Responsive user interface
- Frontend deployed using Vercel
- Backend deployed using Render
- Database hosted using MongoDB Atlas
- Database performance optimization using indexing
