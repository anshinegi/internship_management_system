### Objective
Develop a responsive frontend using HTML, CSS and vanilla JavaScript, integrate it with a REST API, and display API data dynamically.

### Project
Internship Management System
The frontend was developed as part of the Internship Management System project.

### Technologies Used
- HTML5
- CSS3
- JavaScript
- Node.js
- Express.js
- REST API
- Fetch API
- Git and GitHub

### Frontend Features
- Responsive navigation bar
- Hero section
- Internship opportunities section
- About section
- Contact section
- Responsive layout for desktop, tablet and mobile devices
- Dynamically generated internship cards

### API Integration
A REST API was created using Node.js and Express.js.
API endpoint:
`GET /api/internships`
The frontend uses JavaScript's Fetch API to retrieve internship data from the backend.
The fetched data is then dynamically displayed as internship cards on the webpage.

### API Data
Each internship contains:
- Internship ID
- Internship title
- Company name
- Location
- Duration
- Required skills

### Backend
The backend runs locally on:
`http://localhost:5000`

The internship API endpoint is:
`http://localhost:5000/api/internships`
